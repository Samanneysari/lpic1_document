# دورهٔ فارسی خودآموز Linux و LPIC-1

این مسیر برای کسی نوشته شده که ممکن است اولین بار ترمینال Linux را ببیند. هدف فقط حفظ دستور نیست: هر سرفصل با مفهوم، کاربرد، مثال قابل اجرا، توضیح خط‌به‌خط، نتیجهٔ قابل بررسی، خطای رایج و تمرین دارای پاسخ آموزش داده می‌شود.

## این دوره چه چیزهایی دارد؟

- پوشش همهٔ **۴۲ هدف فعال LPIC-1 نسخهٔ 5.0** برای آزمون‌های `101-500` و `102-500`
- **۱۲۹ مثال آموزشی** با توضیح تک‌تک خط‌ها و نتیجهٔ مورد انتظار
- تمرین مستقل و پاسخ تشریحی در پایان هر هدف
- مثال‌های جدا برای Debian/Ubuntu، خانوادهٔ RPM و openSUSE در محل لازم
- هشدار روشن پیش از دستورهای خطرناک storage، boot، network و security
- آزمایشگاه‌های ترکیبی و پروژهٔ پایانی برای تبدیل دانسته‌ها به مهارت

## روش درست استفاده

برای هر هدف این چرخه را انجام دهید:

1. بخش «مفهوم و کاربرد» را با زبان خودتان در دو جمله بازگو کنید.
2. مثال را تایپ کنید؛ promptهایی مثل `$` یا `#` را تایپ نکنید.
3. پیش از Enter نتیجه را حدس بزنید.
4. خروجی را با «نتیجه و بررسی» مقایسه کنید؛ اختلاف نسخه و نام interface طبیعی است، اختلاف مفهوم نه.
5. تمرین مستقل را پیش از بازکردن پاسخ حل کنید.
6. یک خطای کنترل‌شده در VM بسازید، شواهد جمع کنید و آن را برگردانید.
7. در [ماتریس رسمی](../OBJECTIVES.md) هدف را فقط وقتی علامت بزنید که آزمایش مرتبط را مستقل انجام داده‌اید.

## مرز «کامل»

این مجموعه تمام هدف‌های منتشرشدهٔ LPIC-1 نسخهٔ 5.0 را آموزش می‌دهد، اما هیچ متن مستقلی بانک سؤال محرمانهٔ LPI، تمام optionهای همهٔ commandها یا رفتار همهٔ توزیع‌ها را تضمین نمی‌کند. مرجع دقیق نسخهٔ نصب‌شده، `man` همان سیستم است. صفحهٔ رسمی LPI منبع نهایی سرفصل است.

## قانون ایمنی

دستورهای `fdisk`، `parted`، `mkfs`، `mkswap`، `dd`، `fsck`، تغییر GRUB، profile شبکه، SSH و حذف user می‌توانند داده یا دسترسی را از بین ببرند. آن‌ها را فقط در VM مصرفی دارای snapshot و console اجرا کنید. نام device را از مثال کپی نکنید. ابتدا [راهنمای ایمنی](../SAFETY.md) را بخوانید.
