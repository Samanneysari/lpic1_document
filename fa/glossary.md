# واژه‌نامهٔ ساده

[فهرست دوره](README.md)

| واژه | معنی ساده |
|---|---|
| Argument | مقداری که پس از نام command می‌آید و می‌گوید روی چه چیزی کار کند |
| Bootloader | برنامه‌ای که kernel و initramfs را برای شروع Linux بار می‌کند |
| Command | برنامه یا builtinای که shell اجرا می‌کند |
| Daemon/Service | برنامهٔ پس‌زمینه برای ارائهٔ یک وظیفه |
| Device node | فایل ویژه زیر `/dev` برای ارتباط با device |
| Distribution | بستهٔ کامل Linux شامل kernel، ابزار، package manager و policy |
| Environment variable | متغیری که process می‌تواند به فرزند صادر کند |
| Exit status | عدد نتیجهٔ command؛ صفر معمولاً موفقیت است |
| Filesystem | ساختار ذخیره و نام‌گذاری فایل‌ها روی فضای بلوکی |
| Firmware | نرم‌افزار اولیهٔ سخت‌افزار مثل UEFI |
| GID | شمارهٔ هویت گروه |
| Hostname | نام محلی یک host؛ DNS جداگانه باید آن را نگاشت کند |
| Inode | metadata و نشانی دادهٔ فایل؛ نام فایل داخل directory entry است |
| Kernel | بخش مرکزی سیستم‌عامل برای resource و hardware |
| Library | کد قابل استفادهٔ مشترک توسط برنامه‌ها |
| Mount | وصل‌کردن filesystem به یک پوشه |
| Option | بخشی مانند `-l` که رفتار command را تغییر می‌دهد |
| Package | فایل‌های نرم‌افزار همراه metadata نصب و dependency |
| PATH | فهرست پوشه‌هایی که shell برای command می‌گردد |
| PID | شمارهٔ یک process در حال اجرا |
| Process | یک نمونهٔ در حال اجرای program |
| Repository | مخزن packageهای امضاشده/مدیریت‌شده |
| Root filesystem | filesystemی که در `/` دیده می‌شود |
| Root user | حساب مدیریتی با UID صفر |
| Shell | مفسر command مثل Bash |
| Standard input/output/error | ورودی 0، خروجی عادی 1 و خروجی خطا 2 |
| UID | شمارهٔ هویت user |
| Unit | شیء مدیریتی systemd مثل service، socket، timer یا target |
| VM | رایانهٔ مجازی با kernel مستقل از host |
