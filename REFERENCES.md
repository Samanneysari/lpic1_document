## Local manuals

Installed manual pages are authoritative for the exact version on a lab machine:

```bash
man 1 command
man 5 configuration-file
man 7 overview-topic
info coreutils
```

Manual section 1 contains user commands, section 5 contains file formats, section 7 contains overviews and conventions, and section 8 contains administration commands.
