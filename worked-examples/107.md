## 107.1 Users and groups

### What this objective teaches

Read account databases and manage the full user and group lifecycle safely.

### Worked example 1: Resolve an account

```bash
getent passwd root
```

**Line-by-line explanation:**

1. `getent` follows the configured name-service order and requests the passwd record for `root`.

**What to verify:** Seven colon-separated fields appear on a normal system.

### Worked example 2: Read group membership

```bash
id
```

**Line-by-line explanation:**

1. `id` prints the current user's numeric IDs and supplementary groups.

**What to verify:** The primary group follows `gid=` and extra memberships follow `groups=`.

### Worked example 3: Read password aging

```bash
sudo chage -l root
```

**Line-by-line explanation:**

1. `chage -l` lists password-aging policy for `root`; `sudo` is usually needed for complete shadow data.

**What to verify:** This query does not change the password or aging settings.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.

## 107.2 Job scheduling

### What this objective teaches

Choose cron for recurring work, at for one-time work, and systemd timers for unit-based scheduling.

### Worked example 1: List your crontab

```bash
crontab -l
```

**Line-by-line explanation:**

1. `crontab -l` prints the current user's cron table without editing it.

**What to verify:** An error saying no crontab exists simply means none has been created.

### Worked example 2: List queued at jobs

```bash
atq
```

**Line-by-line explanation:**

1. `atq` shows one-time jobs waiting for the `atd` service.

**What to verify:** Each row contains a job number, run time, queue, and owner.

### Worked example 3: List systemd timers

```bash
systemctl list-timers --all
```

**Line-by-line explanation:**

1. `list-timers` shows timer units and their last and next activation; `--all` includes inactive timers.

**What to verify:** A timer normally activates another unit, often a service.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.

## 107.3 Localization and internationalization

### What this objective teaches

Control locale, character encoding, time zone, and predictable command output.

### Worked example 1: Read locale variables

```bash
locale
```

**Line-by-line explanation:**

1. `locale` prints the effective language and category variables for the current process.

**What to verify:** `LC_ALL`, when set, overrides the individual `LC_*` values.

### Worked example 2: Force predictable sorting

```bash
printf '%s\n' b A a | LC_ALL=C sort
```

**Line-by-line explanation:**

1. The assignment applies only to `sort`; the C locale gives a predictable byte-oriented order.

**What to verify:** Uppercase `A` normally sorts before lowercase letters in this locale.

### Worked example 3: Read time-zone status

```bash
timedatectl
```

**Line-by-line explanation:**

1. `timedatectl` reports local time, UTC, RTC, configured zone, and synchronization state.

**What to verify:** In a container, systemd time management may be unavailable.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.
