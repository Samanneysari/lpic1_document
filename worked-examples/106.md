## 106.1 X11

### What this objective teaches

Understand X servers, clients, DISPLAY, authorization, configuration, and Wayland awareness.

### Worked example 1: Read the display address

```bash
printf '%s\n' \"${DISPLAY:-not-set}\"
```

**Line-by-line explanation:**

1. `${DISPLAY:-not-set}` prints DISPLAY when defined or the clear fallback `not-set` otherwise.

**What to verify:** A local X session often uses a value such as `:0`.

### Worked example 2: Inspect X authorization

```bash
xauth list
```

**Line-by-line explanation:**

1. `xauth list` reads X11 authorization records available to the current user.

**What to verify:** No output is normal when no X session or cookie exists.

### Worked example 3: Identify the session type

```bash
printf '%s\n' \"${XDG_SESSION_TYPE:-unknown}\"
```

**Line-by-line explanation:**

1. The parameter expansion prints the session type or `unknown` when the variable is unset.

**What to verify:** Desktop sessions commonly report `x11` or `wayland`.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.

## 106.2 Graphical desktops

### What this objective teaches

Distinguish desktop environments, display servers, display managers, and remote desktop protocols.

### Worked example 1: Read the desktop name

```bash
printf '%s\n' \"${XDG_CURRENT_DESKTOP:-unknown}\"
```

**Line-by-line explanation:**

1. The expansion reads the desktop identifier and supplies `unknown` if no desktop set it.

**What to verify:** Examples include GNOME, KDE, and XFCE.

### Worked example 2: Read session metadata

```bash
loginctl show-session "${XDG_SESSION_ID:-self}" -p Type -p Remote
```

**Line-by-line explanation:**

1. `loginctl show-session` reads a session; the `-p` options keep its display-server type and remote flag.

**What to verify:** This may need a real systemd login session rather than a container shell.

### Worked example 3: Find remote desktop listeners

```bash
ss -ltn | grep -E ':(3389|5900)[[:space:]]'
```

**Line-by-line explanation:**

1. `ss -ltn` lists listening TCP sockets numerically; `grep -E` keeps common RDP or VNC port numbers.

**What to verify:** No output means those common ports are not listening on the inspected host.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.

## 106.3 Accessibility

### What this objective teaches

Recognize visual, hearing, keyboard, pointer, speech, and Braille accessibility features.

### Worked example 1: Check GNOME text scaling

```bash
gsettings get org.gnome.desktop.interface text-scaling-factor
```

**Line-by-line explanation:**

1. `gsettings get` reads the GNOME interface key controlling text scale without changing it.

**What to verify:** This works only when the schema and a suitable desktop session exist.

### Worked example 2: Check high contrast

```bash
gsettings get org.gnome.desktop.a11y.interface high-contrast
```

**Line-by-line explanation:**

1. The command reads the GNOME accessibility boolean for high contrast.

**What to verify:** The result is normally `true` or `false`.

### Worked example 3: Find screen-reader software

```bash
command -v orca || printf '%s\n' 'Orca is not installed'
```

**Line-by-line explanation:**

1. `command -v` searches for Orca; `||` prints a clear message only when that search fails.

**What to verify:** Either an executable path or the fallback message appears.

### Common mistakes and troubleshooting

Do not copy a device name, account name, service name, or path without checking that it exists on your machine. A command that prints nothing may have found no matches; check its exit status with `printf 'status=%s\n' "$?"`. Read permission errors instead of hiding them, and use `man COMMAND` before adding an unfamiliar write or delete option.
