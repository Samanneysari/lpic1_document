# Notebook Topic Map

The notebook list below is grouped by *what the concept helps you understand*. Start with [Linux foundations](00-linux-foundations.md), then follow the objective chapters. A command appearing in a chapter is not a substitute for trying its example and reading the explanation directly below it. Spellings such as `kernel ring biffer`, `proclspci`, `file systemmountlsblk`, and `hqrdlink` are interpreted here as kernel ring buffer, procfs plus `lspci`, filesystem plus `mount` plus `lsblk`, and hard link.
